# Segurança

- dados sintéticos;
- nenhuma credencial ou sessão;
- ações externas, irreversíveis e dados sensíveis permanecem bloqueados ou
  exigem gate humano;
- identidades revogadas não podem agir;
- eventos registram hash de payload;
- memória alterada exige nova versão;
- o sandbox não modifica permissões nem publica artefatos.
