# Governança Charlie Echo — sandbox V1

Implementação sintética do pedido `PEDIDO_CODEX_GOVERNANCA_CHARLIE_ECHO_V1_0`.

Inclui registros de identidade/origem, matriz de permissões, classificador de
risco, gate humano, memória governada, proveniência, log de ações, incidentes,
changelog pedagógico e recertificação.

Não acessa Drive, GitHub, rede, credenciais, dados reais ou permissões externas.
G3/G4 nunca são autorizados sem confirmação humana explícita.
