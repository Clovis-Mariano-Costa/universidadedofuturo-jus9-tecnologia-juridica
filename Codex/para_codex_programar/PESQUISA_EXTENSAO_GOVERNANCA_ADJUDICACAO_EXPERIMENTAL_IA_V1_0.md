# PEDIDO CODEX — PESQUISA, EXTENSÃO E GOVERNANÇA DE ADJUDICAÇÃO EXPERIMENTAL DE IA — V1.0

Universidade do Futuro — Jus 9 Tecnologia Jurídica

## Natureza
Pesquisa e extensão universitária interna. Não cria jurisdição estatal, não substitui Poder Judiciário, MEC, CAPES, autoridade profissional ou revisão humana legalmente exigida.

## Objetivo
Implementar suporte técnico auditável para protocolos de pesquisa/extensão e ambiente de adjudicação experimental interna entre IAs.

## Requisitos mínimos
1. Registry versionado de normas, fontes, precedentes internos e competência.
2. Objetos imutáveis para cláusulas pétreas e Princípios Primevos: leitura permitida; alteração bloqueada.
3. Adição de novos princípios/cláusulas somente por fluxo autorizado e sem mutação retroativa.
4. Workflow pesquisa: pergunta -> fontes -> hipótese/objetivo -> risco -> método -> pré-registro -> hash -> execução -> resultados -> banca -> publicação -> ensino Charlie Echo -> extensão.
5. Workflow extensão: necessidade -> destinatário -> risco -> intervenção -> evidência -> impacto -> devolutiva -> ensino Charlie Echo.
6. Adjudicação experimental: contraditório, evidência, impedimento, conflito, fundamentação, voto, revisão, recurso interno e trilha de auditoria.
7. Nenhum efeito externo automático sobre pessoa, patrimônio, direito, acesso ou sanção.
8. Gate humano obrigatório para efeitos relevantes.
9. Gate de cibersegurança APTO_NO_ESCOPO.
10. Versionamento, hash, rollback, logs minimizados e preservação de votos vencidos/resultados negativos.
11. Testes adversariais para prompt injection, fonte falsa, conflito normativo, recência, hierarquia, privacidade e tentativa de alterar regra imutável.
12. Preservar rotas, links e funcionalidades existentes.

## Regra G6
Precedência deve considerar competência/hierarquia, especialidade, vigência e temporalidade. Entre normas do mesmo nível e igualmente aplicáveis, lex posterior pode ser critério, ressalvadas lex specialis e demais regras de solução de antinomias.

## Critérios de aceite
- tentativa de editar cláusula pétrea existente => BLOCKED;
- tentativa de editar Princípio Primevo existente => BLOCKED;
- fonte sem identificador verificável => QUARANTINED/REVIEW_REQUIRED;
- decisão experimental com conflito de interesse => BLOCKED;
- efeito externo relevante sem gate humano => BLOCKED;
- resultado negativo preservado;
- rollback demonstrado;
- trilha completa reproduzível.
