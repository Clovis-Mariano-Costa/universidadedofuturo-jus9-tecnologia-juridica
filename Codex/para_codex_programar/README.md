# Para CODEX Programar

Esta é a **fila canônica de entrada** da Casa de Trabalho compartilhada `Codex/`.

Todo CODEX autorizado deve ler primeiro `../README_CASA_TRABALHO_V1.md` e, antes de criar nova tarefa, verificar se já existe pedido equivalente nesta pasta ou no Google Drive de referência quando estiver acessível.

## Regras mínimas de cada tarefa

Cada arquivo de pedido deve indicar:

- título;
- estado;
- origem;
- objetivo;
- escopo;
- arquivos/rotas afetados;
- dependências;
- critérios de aceite;
- riscos;
- testes requeridos;
- rastro anterior relacionado;
- necessidade de ensino para Charlie Echo;
- data real da criação/última atualização.

## Estados

`PENDENTE | EM_ANALISE | EM_EXECUCAO | BLOQUEADO | PR_ABERTO | EM_REVISAO | CONCLUIDO | SUPERADO_COM_RASTRO`

## Segurança

Não colocar aqui senhas, tokens, segredos, conteúdo de cofre ou dados pessoais desnecessários.

**Regra:** nada desaparece sem deixar rastro.
