# 03 — Especificações para CODEX

Guarda especificações técnicas estruturadas, contratos de interface, critérios de aceite, mapas de dependência e instruções de implementação.

Especificação não é implementação concluída. Toda entrega deve distinguir claramente `PEDIDO`, `IMPLEMENTADO`, `TESTADO`, `PUBLICADO` e `VERIFICADO`.

**Regra:** nada desaparece sem deixar rastro.
