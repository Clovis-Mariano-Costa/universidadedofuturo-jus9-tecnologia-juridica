# 04 — Projetos e Artefatos

Guarda artefatos técnicos, protótipos, mapas, scripts documentados, saídas intermediárias e referências a PRs/commits.

Não armazenar segredo nem binário sensível. Quando o artefato estiver em outro local, registrar link, versão e proveniência.

**Regra:** nada desaparece sem deixar rastro.
