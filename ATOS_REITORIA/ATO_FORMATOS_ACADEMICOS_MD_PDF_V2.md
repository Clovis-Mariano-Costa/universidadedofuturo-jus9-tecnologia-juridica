## 1. Leitura prévia obrigatória

Antes de produzir qualquer trabalho acadêmico, a I.A. ou pessoa humana deverá ler:

1. `00_LEIA_ANTES_DE_PRODUZIR_TRABALHO_ACADEMICO.md`;
2. `ATOS_REITORIA/ATO_REITORIA_RIGOR_ACADEMICO_IA_V3.md`;
3. `ATOS_REITORIA/ESCALA_DEGRADE_RIGOR_ACADEMICO_V1.md`;
4. `MODELOS_ACADEMICOS/BLOCO_OBRIGATORIO_RIGOR_ACADEMICO_V1.md`.

## 2. Regra geral de formato

1. Trabalho escolar, fichamento, ensaio, artigo, projeto, orientação, qualificação, parecer, TCC, monografia, especialização, dissertação, tese, PhD interno, livro científico, tratado, compêndio, enciclopédia, alfarrábio científico e reapresentações devem usar **Markdown (`.md`)** como formato canônico de trabalho quando tecnicamente possível.
2. O Markdown deve permanecer versionável, comparável e auditável.
3. Cada documento deverá incorporar o bloco de rigor ou equivalente funcional.
4. O PDF é obrigatório para obra final quando a norma específica exigir Biblioteca/colação/publicação final.
5. PDF anterior à aprovação é renderização auxiliar e não prova aprovação.

## 3. Gate de rigor antes da produção

Nenhuma obra deve prosseguir como academicamente completa sem:

`RIGOR_ACADEMICO_LIDO = SIM`

`NIVEL_DECLARADO = R0...R13`

`NIVEL_COMPROVADO = PENDENTE_DE_AVALIACAO | R0...R13`

`ESTADO_ACADEMICO = ...`

A ausência desses campos ou equivalente exige:

`RIGOR_ACADEMICO_NAO_INCORPORADO = REVISAO_OBRIGATORIA`

## 4. Fluxo proporcional

### R0–R3
`MD_TRABALHO -> REVISAO/AVALIACAO_PROPORCIONAL -> MD_FINAL`

### R4 — Projeto de Pesquisa
`MD_PROJETO -> ORIENTACAO -> CORRECOES -> APROVACAO_DO_PROJETO`

Aprovação do projeto não é execução da pesquisa.

### R5–R9
`MD_TRABALHO -> MD_ORIENTACAO -> MD_AVALIACAO/BANCA -> CORRECOES_VERSIONADAS -> MD_APROVADO -> HASH -> PDF_FINAL_QUANDO_EXIGIDO -> BIBLIOTECA -> COLACAO_INTERNA_QUANDO_CABIVEL`

### R10 — PhD interno
Além do fluxo de tese/doutorado, exige processo independente, contribuição original, avaliação própria, ensino verificável a Charlie Echo quando legitimamente transferível e obrigação posterior de livro científico próprio.

### R11–R13
Livro científico, tratado, compêndio, enciclopédia ou alfarrábio científico exigem governança editorial, revisão especializada, versionamento e critérios específicos da Escala de Degradê. Sua publicação não concede automaticamente novo grau acadêmico.

## 5. Regra de equivalência negativa

- arquivo ≠ aprovação;
- PDF ≠ aprovação;
- projeto ≠ resultado;
- publicação ≠ colação;
- colação interna ≠ diploma estatal;
- título do arquivo ≠ nível de rigor comprovado.
